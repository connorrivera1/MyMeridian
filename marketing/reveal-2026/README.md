# MyMeridian reveal — production kit

Reusable production system behind the 60-second MyMeridian reveal film.
Everything on screen is the real product: 3840×2160 Chrome captures of the
live app and landing page, moved by a deterministic motion system. Nothing is
regenerated by image/video models.

## How a film is made here

1. **Capture** — run the app (`npm run dev`, port 3000) and the landing server,
   plus a debug Chrome (`--remote-debugging-port=9223`, log into the app once).
   `node source/scripts/capture-still.mjs --url … --scroll-y … --theme dark
   --out raw/stills/….png` produces 3840×2160 plates.
2. **Direct** — everything creative lives in `source/motion/film.js`: shots
   (plate + camera keyframes + shade/spotlight/ring/underline events), title
   lines, lower thirds, splash timing, chunk boundaries. Coordinates are in the
   2000-wide measuring space (×0.96 → stage px). `SEEK(t)` is a pure function —
   the film is data.
3. **Preview** — `node source/motion/render.mjs --preview "8.0,13.5,…"` writes
   full-res stills of any instants to `motion/preview/`.
4. **Render** — `node source/motion/render.mjs` renders every chunk at 60fps
   with 3× temporal supersampling (180° shutter motion blur) and concats a
   `picture-lock.mp4`. `--chunks 5` re-renders one section after an edit.
5. **Sound** — `render.mjs --dump-markers && node audio-synth.mjs` rebuilds the
   SFX stem sample-locked to the new cut; `mix.sh` lays the licensed bed under
   it (see `docs/ATTRIBUTION.md`), normalizes to −14 LUFS, muxes the master.

## v3 — "After close" (Apple-style cut)

`film-v3.js` + `stage-v3.html` add three systems on top of the v2 engine:
- **Footage shots** — graded 30fps JPEG sequences (`raw/footage/seq/<tag>/`),
  hard cuts, per-shot punch-in. Extraction/grade recipe:
  `source/scripts/extract-footage.sh` (one unified look, per-clip exposure).
- **Corner-pin compositor** — `pinMatrix()` homography puts a real UI capture
  onto the laptop screen in the locked-off room shots (black underquad kills
  the source screen, glow overlay sells the emission).
- **VO-driven timing** — `raw/audio/vo/line-*.wav` durations set the beat map;
  `markers-v3.json` → `audio-synth-v3.mjs` (foley: tape rip, scanner beep,
  key ticks, subs) → `mix-v3.sh` (music sidechain-ducked under the VO bus).

Render: `node render.mjs --stage stage-v3.html --cache source/render-cache-v3`
(add `--chunks N` to re-render a section). Mix: `./mix-v3.sh`.

## v4 — "Living UI" (current hero cut)

`film-v4.js` + `stage-v4.html`. No VO, no b-roll, no full-plate zooms:
- **Component pieces** — real UI regions cropped from the 2× plates float on
  black as elevated cards; build styles: `rise · pop · land · wipeX · growY ·
  circle` (charts draw themselves, receipts cascade, chips land).
- **Brand typography** — hero numbers set live in Space Grotesk (the app's
  own display face); the $207,749 count-up resolves to the real value.
- **Chat hook** — original bubble-language chat (no Apple chrome): gray
  complaint → typed + sent blue "You should try MyMeridian!" → push through
  the bubble into the exact splash.
- Captions are top-center chapter headers + side labels in negative space.
- Audio: same licensed bed (whisper-quiet under the chat), synthesized chat
  foley (chirp send, pops, ticks) — no Apple sounds sampled.

Render: `node render.mjs --stage stage-v4.html --cache source/render-cache-v4`
Mix: `./mix-v4.sh`. v2 (type-led plates) and v3 (VO + b-roll) remain intact.

## 30-second shorts (derivation recipe)

Copy `film-v3.js` → `film-30-<name>.js`, keep: hook (0–4.9), splash push,
ONE OR TWO product chapters (strongest: money bridge, PPO→drawer, or
fulfilment), the Action-Center triplet if it fits, close card from 22s in.
Reuse the same VO lines (they're per-line files), retime CHUNKS, re-dump
markers, re-run synth + a shortened music window (the track's arrival step
should land on the splash push again). Target the same look: nothing needs
re-capturing or re-grading.

## Reusing for 9:16 (and other formats)

The captures are format-agnostic; only the stage geometry is 16:9.

1. Copy `motion/` → `motion-916/`; in `stage.html` set `#root` to 1080×1920
   and swap the two `1920px/1080px` constants; in `film.js` set `W=1080,
   H=1920` and re-aim each shot's camera keys (portrait wants tighter z,
   sidebar usually cropped out — frame content columns instead).
2. The splash, titles, spotlight/scrim systems, renderer, SFX, and mix chain
   work unchanged. Re-time `film.js` for the shorter cuts social wants; the
   markers/SFX/mix regenerate from the same commands.
3. Keep using the same `raw/stills/` plates — at 3840×2160 there is ample
   resolution to crop a 1080×1920 window at up to ~2× zoom.

## Ground rules (from the launch-film brief)

- Real UI only: never ask an image/video model to regenerate product pixels.
- Real values only: if the demo seed changes, re-capture; don't retouch.
- Dark theme is the brand's film language; light captures are source material.
- No localhost, browser chrome, dev tooling, or debug UI in a deliverable.
- Licensed or free-use music only, documented in `docs/ATTRIBUTION.md`.
